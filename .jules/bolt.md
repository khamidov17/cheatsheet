## 2026-06-02 - Optimize history saving with debouncing and parallel API calls
**Learning:** In a real-time collaborative or highly interactive editor, saving state on every keystroke causes significant performance degradation due to network congestion and unnecessary UI re-renders. Debouncing state persistence and parallelizing API requests using Promise.all significantly improves responsiveness. Using fetch keepalive ensures data integrity during page transitions. Robust state management in debounce (clearing timeout ID) is critical to prevent duplicate execution during flush.
**Action:** Always implement debouncing for auto-save features and use Promise.all to parallelize independent backend requests. Use keepalive: true for critical data persistence on unload. Ensure debounce logic correctly manages timer state.
